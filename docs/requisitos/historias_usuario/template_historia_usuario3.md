# História de Usuário: Beatriz Souza

## Título
Navegação por categorias segmentadas por interesse e localização

## Narrativa
**Como** Beatriz Souza, estudante de Medicina na UFMG,  
**Eu quero** navegar por categorias como “disciplinas obrigatórias”, “iniciação científica”, “internato” e “eventos em BH”,  
**Para que** encontrar facilmente discussões relevantes para minha realidade acadêmica e geográfica.

## Critérios de Aceitação
- [ ] A plataforma deve apresentar categorias claras e organizadas por temas acadêmicos e localização geográfica.  
- [ ] As categorias devem ser personalizáveis conforme o curso e instituição do usuário.  
- [ ] Deve ser possível filtrar conteúdos, fóruns e eventos por localização (ex: cidade, estado).  
- [ ] O usuário deve poder acessar rapidamente as discussões mais recentes ou populares em cada categoria.  
- [ ] A interface deve ser intuitiva e responsiva para navegação tanto em desktop quanto em mobile.  
- [ ] O sistema deve garantir que as categorias exibidas sejam relevantes para o perfil do usuário (curso e instituição).

## Detalhes Técnicos
- Estrutura de categorias no banco de dados (hierarquia de temas e localização).  
- Sistema de filtros por tags, localização e curso.  
- Interface com menus dinâmicos e responsivos.  
- Integração com base de dados de eventos acadêmicos regionais.  
- Cache para melhorar performance na navegação entre categorias.

## Dependências
- Cadastro atualizado dos cursos e locais dos usuários.  
- Banco de dados de eventos acadêmicos locais.  
- Sistema de perfis de usuários com dados de curso e localização preenchidos.
